Lesson 1: What is the DOM?

DOM = Document Object Model

It is a tree-like structure representing your HTML page. Every element, attribute, text node is a node in the DOM.

<!DOCTYPE html>
<html>
<head>
<title>DOM Example</title>
</head>
<body>
<h1>Hello World</h1>
<p>This is a paragraph.</p>
</body>
</html>

DOM tree looks like:
html
head
title
body
h1
p

Lesson 2: DOM Tree Structure

Parent Child Sibling relationship

<div id="parent">
<p id="child1">Child 1</p>
<p id="child2">Child 2</p>
</div>

div#parent - parent
p#child1 & p#child2 - children
Child1 & Child2 - siblings

Understanding this helps in selecting and manipulating elements.

Lesson 3: Selecting Elements

JavaScript interacts with elements using selectors.

const heading = document.getElementById("myHeading");
const paragraphs = document.getElementsByTagName("p");
const firstDiv = document.querySelector("div");
const allDivs = document.querySelectorAll("div");

getElementById("id") - select one element by ID.
getElementsByTagName("tag") - selects all elements by tag.
querySelector("selector") - selects first matching element
querySelectorAll("selector") - selects all matching elements.

Summary

DOM is a tree representation of your webpage.
Elements have parent, child, and sibling relationships.
Selecting elements is the first step to manipulating the page with Javascript.
Understanding the DOM unlocks interactive web pages.
