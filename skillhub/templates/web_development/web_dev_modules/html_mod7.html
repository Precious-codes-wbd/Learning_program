Lesson 1: Creating a Table (<table>)

Use <table> to organize data in rows and columns.

<table border="1">
<tr>
<th>Name</th>
<th>Age</th>
</tr>
<tr>
<td>Precious</td>
<td>18</td>
</tr>
<tr>
<td>Teddy</td>
<td>19</td>
</tr>
</table>

How it will appear on your browser:

Name Age
Precious 18
Teddy 19

<table> - starts table.
border="1" - adds border.
<tr> - table row.
<th> - table header (bold and centered).
<td> - table data (cells).

Lesson 2: Table Rows <tr>

Each <tr> is one row of the table. It can contain <th>(headers) or <td>(data).

Lesson 3: Table Headings <th>

<th> is for header cells. It is usually bold and centered and it gives meaning to each column.

Lesson 4: Table Data <td>

<td> is for actual data. It is placed inside <th> and can contain text, numbers, or even images.

Lesson 5: Styling and Organizing Tables

<td> You can use CSS to style:

<table style="border-collapse: collapse; width: 50%;">
<tr>
<th style="background-color: #f2f2f2;">Name</th>
<th style="background-color: #f2f2f2;">Age</th>
</tr>
<tr>
<td>Precious</td>
<td>18</td>
</tr>

How it will appear on your browser:

Name Age
Precious 18

border collapse: collapse; - removes double borders.
background color - color hearders or rows.
Tables can also have padding and alignment using CSS.

Summary

<table> - container for table.
<tr> - row.
<th> - header.
<td> - data.
Style with CSS for better readability.
