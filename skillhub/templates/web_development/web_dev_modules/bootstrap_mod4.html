Lesson 1: Form Inputs

Bootstrap styles form inputs automatically for a clean look.

<body>
<form>
<div class="mb-3">
<label for="name" class="form-label">Name</label>
<input type="text" class="form-control" id="name" placeholder="Enter your name">
</div>
<div class="mb-3">
<label for="email" class="form-label">Email</label>
<input type="email" class="form-control" id="email" placeholder="Enter your email">
</div>
<button type="submit" class="btn btn-primary">Submit</button>
</form>
</body>

How it will appear on your browser:

Classes explained:
form-control - styles input fileds.
mb-3 - adds margin-bottom.
btn btn-primary - styled submit button.

Lesson 3: Form Validation

Bootstrap makes validation easy.

<body>
<form class="needs-validation" novalidate>
<div class="mb-3">
<label for="email" class="form-label">Email</label>
<input type="email" class="form-control" id="email" required>
<div class="invalid-feedback">
Please enter a valid email.
</div>
</div>
<button type="submit" class="btn btn-primary">Submit</button>
</form>
<script>
// Example: simple validation
(() => {
'use strict'
const forms = document.querySelectorAll('.needs-validation)
Array.from(forms).forEach(form => {
form.addEventListener('submit', event => {
if (!form.checkValidity()) {
event.preventDefault()
event.stopPropagation()
}
form.classList.add('was-validated)
}, false)
})
})()
</script>
</body>

How it will appear on your browser:

Please enter a valid email.

required- field must be filled.
invalid-feedback - message when input is invalid.
was-validated - triggers Bootstrap styling.

Summary

Form input: styled with form-control.
Layouts: inline or grid for neat arrangement.
Validation: built-in, shows feedback when invalid.
Bootstrap forms are responsive and visually appealing.
