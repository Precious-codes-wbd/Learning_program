Lesson 1: For Loops

for loop run a block of code a fixed number of times.

let(i = 1,i <= 5, i++ ){
console.log("Hello", i);
};

Explanation:
let i = 1 - start counting from 1
i <= 5 - loop runs while i is <= 5
i++ - increase i by 1 after each loop
Output: Hello 1, Hello 2, Hello 3....Hello 5

Lesson 2: While Loop

while loops run as long as a condition is true.

let i = 1;
while(i <= 5){
console.log("Hi", i);
i++;
};

Be careful with while loops to avoid infinite loops.

Lesson 3: Do-While Loop

do-while loops run at least once, then check the condition.

let i = 1;
do{
console.log("Hey", i);
} while(i <= 5);

If the condition is false at first, the code runs once.

Summary

for loop: repeat code a fixed number of times.
while loop: repeat code while condition is true.
do-while loop: runs at least once, then checks condition.
Loops helps automate repetitive tasks.
