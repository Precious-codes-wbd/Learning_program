Lesson 1: Understanding the Box Model

Every HTML element is treated as a rectangular box. The box has 4 parts:

  • Content - text, image, or other content inside the box.
  • Padding - space inside the box between content and border.
  • Border - line around the padding and content.
  • Margin - space outside the box, seperating it from other elements.

Lesson 2: Padding

Padding = space between content and border.

In your index.html:

<p>This is a paragraph</p>

In your style.css:

p{
padding : 20px; /* 20px space inside the box */
background-color: lightyellow;
border: 1px solid black;
}

How it will appear on your browser:

This is a paragraph

Can set top, right, bottom, left individually:

  • padding-top : 10px;
  • padding-bottom : 10px;
  • padding-right : 15px;
  • padding-left : 15px;

Lesson 3: Margin

Margin = space outside the box.

In your index.html:

<div>
<p>This is a paragraph</p>
</div>

In your style.css:

div{
margin : 20px;
background-color: lightblue;
}

How it will appear on your browser:

This is a paragraph

Can also set each side individually:

  • margin-top : 10px;
  • margin-right : 15px;
  • margin-bottom : 10px;
  • margin-left : 15px;

Auto margins can center a block element horizontally:

In your index.html:

<div>
<h2>SkillHub</h2>
<p>This is a paragraph</p>
</div>

In your style.css:

div{
width : 200px;
margin: 0 auto/* centers the div */
border: 1px solid black;
}

How it will appear on your browser:

SkillHub

This is a paragraph

Lesson 4: Border

Border surrounds content + padding. CSS properties: border-width, border-style, border-color.

In your index.html:

<p>This is a paragraph</p>

In your style.css:

p{
padding: 10px;
border: 1px solid red;
border-style: dashed;
}

How it will appear on your browser:

This is a paragraph

Border styles: solid, dotted, dashed, double, none.

Lesson 5: Width and Height

Set the size of content area using width and height.

In your index.html:

<div>
<p>This is a paragraph</p>
</div>

In your style.css:

div{
width : 300px;
height : 150px;
padding : 20px;
border: 5px solid black;
margin : 10px;
}

How it will appear on your browser:

This is a paragraph

Total space taken = width + padding + border + margin.

Summary

Every element = box (content + padding + border + margin).
Padding: inside space.
Border: edge of the box.
Margin: outside space.
Width & height: size of the content.
Understanding the box model is key for layout control.
