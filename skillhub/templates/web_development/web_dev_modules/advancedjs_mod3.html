Lesson 1: Changing Text (innerText)

innerText changes the visible text of an element.

const heading = document.getElementById("myHeading");
heading.innerText = "Hello, Precious!";

Updates the text without affecting HTML structure.

Lesson 2: Changing HTML (innerHTML)

innerHTML changes the HTML content inside an element.

const box = document.getElementById("box");
box.innerHTML = "<h2>New Heading</h2><p>New Paragraph</p>";

Lets you add new tags, links, images dynamically.

Lesson 3: Changing Styles

Change CSS properties directly via JavaScript.

const button = document.querySelector("button");
button.style.backgroundColor = "green";
button.style.color = "white";
button.style.fontSize = "20px";

Styles gets updated immediately on the page. Works with any CSS property.
(camelCase for multi-word names, e.g, backgroundColor, fontWeight)

Summary

innerText - update only text.
innerHTML - update HTML content (tags included).
style property - update CSS styles dynamically.
