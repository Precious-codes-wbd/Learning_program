Lesson 1: Creating Elements

Use document.createElement() to make a new element.

const newDiv = document.createElement("div");
newDiv.innerText = "Hello, Precious!";
newDiv.style.backgroundColor = "lightgreen";
newDiv.style.padding = "10px";
document.body.appendChild(newDiv);

Steps:
Create element - createElement("tag")
Add content - innerText or innerHTML
Add styles - style
Append to page - appendChild(parent)

Lesson 2: Appending Elements

You can append elements inside specific parents.

const parent = document.getElementById("container");
const newParagraph = document.createElement("p");
newParagraph.innerText = "This is a new paragraph";
parent.appendChild(newParagraph);

Parent element can be any container (div, section etc.)

Lesson 3: Removing Elements

Use removeChild() to delete elements.

const container = document.getElementById("container");
const paragraph = document.getElementById("p1");
container.removeChild(paragraph);

Or use element.remove() directly.

const paragraph = document.getElementById("p2");
paragraph.remove();

Lets you dynamically delete content.

Summary

createElement() - make new HTML elements.
appendChild() - add elements to the page.
removeChild() or remove() - delete elements.
