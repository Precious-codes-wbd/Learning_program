Lesson 1: Element Selectors

Element selector targets all elements of a certain type.
Syntax : element {property: value;}

In your index.html:

<body>
<p>This is a paragraph</p>
<p>Another paragraph</p>
</body>

In your style.css:

p{
color: blue;
font-size: 18px;
}

Both <p> tags turn blue and have 18px font size. The style is for all <p> elements.

How it will appear on your browser:

This is a paragraph

Another paragraph

Lesson 2: Class Selectors

Class selector targets elements with a specific class.
Syntax : .classname {property: value;}

Example:

In your index.html:

<body>
<p class="highlight">Important text</p>
<p class="highlight">Another important text</p>
<p>Normal text</p>
</body>

In your style.css:

.highlight{
background-color: yellow;
font-weight: bold;
}

How it will appear on your browser:

Important text

Another important text

Normal text

Only elements with class highlight are styled and class selectors are styled using "." - .highlight

Lesson 3: ID Selectors

ID selector targets a single element with a unique ID.
Syntax : #idame {property: value;}

Example:

In your index.html:

<body>
<h1 id="main-title">Welcome to SkillHub</h1>
</body>

In your style.css:

#main-title{
color: purple;
text-align: center;
}

How it will appear on your browser:

Welcome to SkillHub

Only the element with ID main-title is styled and ID selectors are styled using "#" - #main-title
Reminder: IDs should be unique on a page.

Lesson 4: Grouping Selectors

Grouping selectors apply the same style to multiple elements.
Syntax : selector1, selector2 {property: value;}

Example:

In your index.html:

<body>
<h1>Heading</h1>
<p>Paragraph</p>
<span>Span text</span>
</body>

In your style.css:

h1, p, span{
font-family: Arial, sans-serif;
color: green;
}

How it will appear on your browser:

Heading

Paragraph

Span text

All three elements share the same font and color.

Lesson 5: Descendant Selectors

Descendant selector targets inside another element.
Syntax : parent child {property: value;}

Example:

In your index.html:

<body>
<div>
<p>Text inside div</p>
</div>
<p>Text outside div</p>
</body>

In your style.css:

div p{
color: red;
}

How it will appear on your browser:

Text inside div

Text outside div

Only <p> inside <div> is red.

Summary

Element selector - all elements of a type.
Class selector - elements with a class(.)
ID selector - unique elements(#)
Grouping selectors - same style for multiple elements.
Descendant selectors - target elements inside another element.
