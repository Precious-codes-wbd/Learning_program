Lesson 1: What is Boostrap?

Bootstrap is a CSS framework that helps you create responsive websites faster. Features include:

  1. Grid systems for layouts.
  2. Pre-designed components (buttons, cards, forms).
  3. Utilities for spacing, colors and visibility.

Advantages:

  1. Saves time - no need to write all CSS from scratch.
  2. Mobile-friendly - automatically adjusts for phones, tablets, desktop.
  3. Consistent design across browsers.

Lesson 2: Adding Bootstrap to a Project

There are two main ways to include Boostrap:

  • CDN (Content Delivery Network) - fastest way, no files included but you need to be online.
    <!DOCTYPE html>
    <html>
    <head>
    <title>Boostrap Example</title>
    <!-- Boostrap CSS -->
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet" >
    </head>
    <body>
    <h1 class="text-primary">Hello, Bootstrap!</h1>
    </body>
    </html>

    How it will appear on your browser:

    Hello, Bootstrap!

  • Download Boostrap - include the files locally.
    • Download from getbootstrap.com
    • Link the CSS and JS files in your HTML.
    • After downloading the file, go to file explorer and right click on the file, then click extract all.
    • Write this in your index.html
      <!DOCTYPE html>
      <html>
      <head>
      <title>Boostrap Example</title>
      <!-- Boostrap CSS -->
      <link href="bootstrap-5.3.8-dist/css/bootstrap.min.css" rel="stylesheet" >
      </head>
      <body>
      </body>
      <script src="bootstrap-5.3.8-dist/js/bootstrap.bundle.min.js" rel="stylesheet" >
      </html>
    • You can use Boostrap offline.

Lesson 3: Bootstrap Containers

Containers are the main layout wrapper in Bootstrap.

There are two types:

  • .container - fixed width, responsive
    <body>
    <div class="container">
    <h2>Fixed Container</h2>
    <p>This content is centered and responsive!</p>
    </div>
    </body>

    How it will appear on your browser:

    Fixed Container

    This content is centered and responsive

  • .container-fluid - full width, stretches
    <body>
    <div class="container-fluid">
    <h2>Fixed Width Container</h2>
    <p>This content stretches the full width on the screen.</p>
    </div>
    </body>

    How it will appear on your browser:

    Fixed Container

    This content stretches the full width on the screen.

Containers keep content aligned and responsive.

Summary

Bootstrap - CSS framework for fast, responsive websites.
Can be aded via CDN or local download.
Conatiners organize your layout (.container, .container-fluid)
Makes websites mobile-friendly and consistent.
