Lesson 1: Ordered Lists <ol>

Ordered lists are numbered lists.

<ol>
<li>Wake Up</li>
<li>Brush teeth</li>
<li>Have breakfast</li>
<ol>

How it will appear on your browser:

  1. Wake up
  2. Brush teeth
  3. Have breakfast

<ol> - ordered list.
<li> - list them.

Lesson 2: Unordered Lists <ul>

Unordered list use bullet:

<ul>
<li>Apples</li>
<li>Bananas</li>
<li>Oranges</li>
</ul>

How it will appear on your browser:

  • Apples
  • Bananas
  • Oranges

<ul> - unordered list.
<li> - list them.

Lesson 3: Nested Lists

You can put a list inside another list.

<ol>
<li>Fruits
<ul>
<li>Apples</li>
<li>Bananas</li>
<li>Oranges</li>
<ul>
<li>Vegetables</li>
<ol>

How it will appear on your browser:

  1. Fruits
    • Apples
    • Bananas
    • Oranges
  2. Vegetables

Nested lists are good for subcategories.

Lesson 4: Real-Life Examples of Lists

Shopping list - <ul>

Instructions/Steps - <ol>

Menus - <ul>

Summary

<ol> - numbered list.
<ul> - bulleted list.
<li> - list item.
Lists can be nested.
Use lists for organization and readability.
