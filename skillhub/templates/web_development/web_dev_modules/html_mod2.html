Lesson 1: Understanding <!DOCTYPE html>

This is the first line in every HTML document.

<!DOCTYPE html>

What this means:
"This document is written in HTML5".

Key Idea:
It is not a tag.
It helps the browser display your page correctly.

Lesson 2: The <html> tag

This is the root of the HTML document. Everything on your webpage must be inside it.

<html>

Lesson 3: The <head> tag

Contains:

  • Page title
  • Meta information
  • Links to CSS or scripts

<head>

Important:
Content inside <head> is not shown on the webpage.

Lesson 4: The <title> tag

Sets the name of the page. Appears on the browser tab.

<title></title>

Example:
If you write:

<title>Precious's Site</title>

Your browser tab will show: Precious's Site

Lesson 5: The <body> section

This is where everything visible goes:

  • Text
  • Images
  • Links
  • Buttons

<body></body>

Example:

<body>
<h1>Hello</h1>
<p>Welcome to my page</p>
</body>

Full Structure Example

<!DOCTYPE html>
<html>
<head>
<title>My Page</title>
</head>
<body>
<h1>Hello Precious</h1>
<p>This is your page</p>
</body>
</html>

Summary

<!DOCTYPE html> - tells browser HTML5.
<html> - root element.
<head> - hidden info.
<title> - tab name.
<body> - visible comtent
