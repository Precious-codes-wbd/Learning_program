Lesson 1: What is HTML?

HTML (HyperText Markup Language) is the standard language used to create webpages. It structures content on the web. It tells the browser what to display.

Example:
<h1>Hello World</h1>
<p>This is a webpage</p>

Key Idea:
HTML is not a programming language _ it is a markup language.

Lesson 2: How Websites Work

A website works using three main parts:
  1. Client (Browser) what users use (Chrome, Safari).
  2. Server where the website files are stored.
  3. Internet connects them.

Process:
You type a website name, browser sends request to server, server sends back HTML,CSS, JS, Browser displays it.

Lesson 3: Web Browsers and Servers

Web Browser

A browser is software used to view websites.

Examples:
  • Chrome
  • Firefox
  • Edge
Web Server

A server is a computer that stores website files and sends them when requested.

Key Idea:
Browser = displays
Server = stores and sends

Lesson 4: Installing a Code Editor (VS Code)

A code editor is where you write your HTML code.

Popular editor: VS Code (Visual Studio Code)

Steps:
  • Download VS Code
  • Install it
  • Open it
  • Create a new file

Useful feature: Syntax highlighting (makes code colorful and readable).

Lesson 5: Creating Your First HTML File

Steps:

  1. Open VS Code
  2. Create a new file
  3. Save it as: *index.html*
  4. Write this:

    5. <!DOCTYPE html>
    <html>
    <head>
    <title>My First Page</title>
    </head>
    <body>
    <h1>Hello World!</h1>
    <p>This is my first webpage</p>
    </body>
    </html>

  5. Open it in your browser

Key Idea:
.html extention is important (index.html).
HTML files are openeed in your browser.
Always save your file before opening.

Summary

HTML is used to structure webpages.
Websites work using browser + server.
Your write code in a code editor.
Your first file must end with .html

Steps to Creating a proper file:

  1. Open File Explorer
  2. Go to documents, create a folder, you can name it 'Project' or any name of your choice.
  3. Open VS Code.
  4. Click open folder.
  5. Then go to documents and select the folder you created ('Project').
  6. After selecting, click on the file icon, then you will see a another file icon with a '+' sign underneath it, Click it and create a file.
  7. Reminder: Your first file must be index.html so name your file index.html.
  8. Shortcut: Shift 1 + Enter key or you can copy the code under Lesson 5.
  9. If you want to view your site on the browser, you have to download this extension 'Live Server'.
  10. In your VS Code, at the right side where there is the file icon you will see another icon with the name 'Extension', Click it and download 'Live Server'.
  11. Then in your index.html, right click on the page and click on 'Open with Live Server'.
