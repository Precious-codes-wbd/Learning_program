Lesson 1: HTML Headings (<h1> to <h6>)

HTML has six levels of headings:

  1. <h1>Biggest heading</h1>
  2. <h2>Second biggest</h2>
  3. <h3>Smaller</h3>
  4. <h4>Smaller</h4>
  5. <h5>Smaller</h5>
  6. <h6>Smallest heading</h6>

Example: (Copy this in your file(index.html) in your VS Code)

<!DOCTYPE html>
<html>
<head>
<title>My Page</title>
</head>
<body>
<h1>This is heading 1</h1>
<h2>This is heading 2</h2>
<h3>This is heading 3</h3>
<h4>This is heading 4</h4>
<h5>This is heading 5</h5>
<h6>This is heading 6</h6>
</body>
</html>

How it will appear on your browser:

This is heading 1

This is heading 2

This is heading 3

This is heading 4

This is heading 5
This is heading 6

Key Idea:
Headings help structure your content and are good for SEO.

Lesson 2: Paragraphs (<p>)

Paragraphs are blocks of text. Each <p> starts on a new line. Browsers add space after paragraphs automatically.

<!DOCTYPE html>
<html>
<head>
<title>My Page</title>
</head>
<body>
<p>Welcome to my page.</p>
<p>My name is Precious.</p>
</body>
</html>

How it will appear on your browser:

Welcome to my page.

My name is Precious.

Lesson 3: Line Breaks (<br>)

Use <br> to break a line without starting a new paragraph. It is a self-closing tag, no need for </br>

<!DOCTYPE html>
<html>
<head>
<title>My Page</title>
</head>
<body>
<p>Welcome to my page. <br> My name is Precious.</p>
</body>
</html>

How it will appear on your browser:

Welcome to my page.
My name is Precious.

Lesson 4: Horizontal Lines (<hr>)

A horizontal line seperates content:

<hr>

How it will appear on your browser:

It is self-closing and useful to divide sections.

Lesson 5: Text Formatting (<b>, <i>, <strong>)

<b> - Bold Text

<i> - Italics

<strong> - Strong Importance

<!DOCTYPE html>
<html>
<head>
<title>My Page</title>
</head>
<body>
<b>This is bold.</b>
<i>This is italic.</i>
<strong>This is an important text.</strong>
</body>
</html>

How it will appear on your browser:

This is bold. This is italic. This is an important text.

Key Idea:
<strong> is better than <b> for acccessibility and SEO.

Summary

<h1> to <h6> - headings.
<p> - paragraph.
<br> - line break.
<hr> - horizontal line.
<b>, <i>, <strong> - text formatting.
