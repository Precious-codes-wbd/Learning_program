Lesson 1: Display Property

Controls how an element is displayed on a page.

Common values:

  • block - element takes full width, starts on a new line.

    div{
    display: block;
    }

  • inline - element flows with text, does not start on a new line.

    div{
    display: inline;
    }

  • inline-block - inline element but can have width and height.

    div{
    display: inline-block;
    }

  • none - element is hidden completely.

    div{
    display: none;
    }

Lesson 2: Block vs Inline Element

Block elements - <div>, <h1>, <p>, <section>
Starts on a new line. Can have width & height.

Inline elements - <span>, <a>, <strong>
Flow with text. Width and height cannot be set.

Inline-block - hybrid; behaves like inline but supports width and height.

Lesson 3: Position Property

Controls where an element is placed static(default) - normal flow of page.

Relative - positioned relative to its normal position.

Absolute - positioned relative to nearest positioned ancestor.

<div>
<div> </div>
</div>

In your style.css:

div{
background-color: purple;
width: 200px;
height: 150px;
position: relative;
top: 10px; /* moves down */
left: 30px; /* moves right */
}
div{
background-color: blue;
width: 200px;
height: 150px;
position: absolute;
top: 50px;
left: 70px;
}

How it will appear on your browser:

Fixed - stays in the same place even when scrolling.

header{
position: fixed;
top: 0;
width: 100%;
}

Sticky - scrolls until a point, then sticks.

Lesson 4: Overflow

Controls what happens when content overflows its container.

Values:
visible - default, content spills out.
hidden - content cut off.
scroll - scrollbars added.
auto - scrollbars added only if needed.

div{
width: 200px;
height: 100px;
overflow: scroll;
}

Lesson 5: Visibility

Controls whether element is visible or invisible.
visible - element is seen.
invisible - element invisible but still takes space.

p{
visibility: hidden; /* hidden but space remains */
}

Summary

Display - block, inline, inline-block, none.
Position - static, relative, absolute, fixed, sticky.
Overflow - visible, hidden, scroll, auto.
Visibility - visible, hidden.
Understanding these controls how elements appear and behave on a page.
