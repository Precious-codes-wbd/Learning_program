Lesson 1: Creating Links <a>

The <a> tag is used to create clickable links

<a href="https://www.google.com">Go to Google</a>

href - the destination URL.
Text inside <a> - what user clicks.

How it will appear on your browser:

Go to Google

Lesson 2: Linking to External Websites

<a href="https://www.wikipedia.org">Visit Wikipedia</a>

Opens the website in the same tab by default.
Good for referencing other resources.

How it will appear on your browser:

Visit Wikipedia

Lesson 3: Linking to Pages Within Your Site

Suppose you have:

  • index.html
  • about.html

Link from index to about:

<a href="about.html">About Us</a>

This is called a relative link.
Relative - path within your own website.

About Us

Lesson 4: Opening Links in New Tabs

Add target="_blank:

<a href="https://www.google.com target="_blank">Open Google in new tab</a>

Open link in a new browser tab.

How it will appear on your browser:

Open Google in new tab

Lesson 5: Creating Navigation Menus

Navigation menus help users move through your site:

<nav>
<a href="index.html">Home</a> |
<a href="about.html">About</a> |
<a href="contact.html">Contact</a>
</nav>

How it will appear on your browser:

Home | About | Contact

<nav> - semantic tag for menus.
Use | or CSS for styling.

Summary

<a> - create links.
href - destination.
_blank - open in new tab.
Relative links - within your site.
<nav> - group links for navigation.
