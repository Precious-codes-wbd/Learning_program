Lesson 1: Arithmetic Operators

Arithmetic operators are used for math operations.

Operator Meaning Example
+ Addition 5 + 3 = 8
- Substraction 5 - 3 = 2
* Multiplication 5 * 3 = 15
/ Division 15/3 = 5
% Modulus (remainder) 10 % 3 = 1
** Exponentiation 2**3 = 8

Example in JS:

let a = 10;
let b = 3;
console.log(a + b); //13
console.log(a - b); //7
console.log(2 ** 3); //8

Lesson 2: Comparison Operators

Used to compare values, result is true or false.

Operator Meaning Example
== Equal 5 == "5" - true
=== Strict equal 5 === "5"- false
!= Not equal 5 != 3 - true
!== Strict not equal 5 !== "5"
> Greater than 5 > 3 - true
< Less than 5 < 3 - false
>= Greater or equal 5 >= 5 - true
<= Less or equal 3 <= 5 - true

Example in JS:

let x = 5;
let y = 10;
console.log(x < y); // true
console.log(x === 5); // true

Key Idea:
"===" is strict because it obeys both numbers and string, like the example given 5 === "5", both numbers are the same but one is a string and the other is a number, that is why the result is false. The same goes for "!===" : strict not equal.

Lesson 3: Logical Operators

Combine conditions and return true or false.

Operator Meaning Example
&& AND (all true) true && false - false
|| or true || false - true
! Not (invert) !true - false

Example in JS:

let isStudent = true;
let hasID = false;
console.log(isStudent && hasID); // false
console.log(!isStudent); // false

Summary

Arithmetic Operators: +, -, *, /, %
Comparison Operators: ==, ===, !=, !==, >, <, >=, <=
Logical Oprators: &&(and), ||(or), !(not)
Operators are the building blocks of programming logic.
