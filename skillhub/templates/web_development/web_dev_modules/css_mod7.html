Lesson 1: Introduction to CSS Grid

CSS Grid is a 2-dimensional layout system. You can control both rows and columns at the same time. Works on a parent container (grid container) and its children (grid items).

Why use Grid?

  • Perfect for complex layout.
  • Combine rows and columns easily.
  • Align items in both directions.

Lesson 2: Grid Container

To use CSS Grid, set the parent element as a grid container:

In your index.html:

<div class="container">
<div>Item 1</div>
<div>Item 2</div>
<div>Item 3</div>
<div>Item 4</div>
</div>

In your style.css:

.container{
display: grid;
}

All direct children of .container become grid items.

Lesson 3: Grid Rows and Columns

Use grid-template-columns and grid-template-rows to define number and size of columns/rows.

In your index.html:

<div class="container">
<div style="background-color: red">Item 1</div>
<div style="background-color: green">Item 2</div>
<div style="background-color: blue">Item 3</div>
<div style="background-color: yellow">Item 4</div>
</div>

In your style.css:

.container{
display: grid;
grid-template-columns: 100px 200px 100px; /* 3 columns */
grid-template-rows: 50px 100px; /* 2 rows */
}

How it will appear on your browser:

Item 1
Item 2
Item 3
Item 4

We have two rows and three columns
The first row is 50px and the second is 100px that is why item 4 box is longer than item 1.
We have three columns, the first one is 100px, the second 200px and the third one 100px. Item 2 is longer than Item 1 and Item 3 because it is the one taking the highest pixels: 200px.

You can use fractions (fr):

.container{
grid-template-columns: 1fr 2fr 1fr; /* second column is twice as wide */
}

Lesson 4: Grid Gaps

gap (or row-gap & column-gap) controls spacing between grid items.

In your style.css:

.container{
display: grid;
grid-template-columns: repeat(3, 1fr);
gap: 10px;
}

Lesson 5: Building Layouts with Grid

You can position items in specific rows/columns.

In your index.html:

<div class="container">
<div class="Item1">Item 1</div>
<div class="Item2">Item 2</div>
</div>

In your style.css:

.container{
display: grid;
}
.Item1{
grid-column: 1 / 3; /* spans from column 1 to 2 */
grid-row: 1 / 2; /* first row */
}
.Item2{
grid-column: 3 / 4;
grid-row: 1 / 3; /* spans 2 rows */
}

How it will appear on your browser:

Item 1
Item 2

Combine with Flexbox inside grid items for advanced layouts.

Summary

CSS Grid = 2D layout system.
Grid container: display: grid;
Grid rows/columns: grid-template-rows, grid-template-columns.
Gaps: spacing between items.
Item placement: control position with grid-row and grid-column.
Grid + Flexbox = Very powerful layout tools.
