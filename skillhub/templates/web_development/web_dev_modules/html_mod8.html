Lesson 1: Introduction to Forms

Forms allow user input on webpage. Tags used: <form>

<form action="/submit" method="post">
<!--input go here-->
</form>

action - URL to send data.
method - GET or POST.

Lesson 2: Text Inputs

<form action="/submit" method="post">
<label for="name">Name: </label>
<input type="text" id="name" name="name" placeholder="Enter your name">
</form>

How it will appear on your browser:

type = "text" - simple text box.
placeholder - hint for user.
<label> - connects text to input.

Lesson 3: Radio Buttons and Checkboxes

Radio Buttons - select one option:

<form action="/submit" method="post">
<input type="radio" name="gender" value="male">Male
<input type="radio" name="gender" value="female">Female
</form>

How it will appear on your browser:

Male Female

Checkboxes - select multiple options:

<form action="/submit" method="post">
<input type="checkbox" name="hobby" value="reading">Reading
<input type="checkbox" name="hobby" value="sports">Sports
<input type="checkbox" name="hobby" value="music">Music
</form>

How it will appear on your browser:

Reading Sports Music

Radio Buttons - Can select only one option.
Checkboxes - Can select more than one option.
