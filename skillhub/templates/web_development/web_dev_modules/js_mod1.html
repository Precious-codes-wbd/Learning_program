Lesson 1: What is JavaScript?

JavaScript (JS) is a programming language used to make websites interactive and dynamic.

Examples of JS in action:

  • Clicking a button to show a message.
  • Animating a menu.
  • Validating form inputs.
  • Updating content without reloading the page.

Key Idea:
Runs in the browser(client-side).
Can also run on the server(Node.js).
Works with HTML and CSS.

Lesson 2: Adding JavaScript to HTML

  1. Inline JavaScript - directly inside an element.

    <button onclick="alert('Hello!')" >Click Me</button>

    How it will appear on your browser:

  2. Internal JavaScript - inside <script> tag.

    <!DOCTYPE html>
    <html>
    <head>
    <title>JS Example</title>
    </head>
    <body>
    <h1>Welcome</h1>
    <script>
    alert("Hello from internal JS!");
    </script>
    </body>
    </html>

  3. External JavaScript - seperate .js file linked to HTML.

    <script src="script.js"></script>

    External script.js file example:

    console.log("Hello from external JS!");

    Best practice: use external JS for bigger projects.
    Keeps HTML clean and organized.

Lesson 3: Writing Your First Script

  • Create a file script.js in your project folder.
  • Link to your HTML - write this in your index.html:

    <head>
    <script src="script.js"></script>
    </head>

  • Simple JS example: display a message in the browser console.

    console.log("Hello, I am learning Javascript!");

  • Open browser Right click Inspect Console to see the message.
  • Another example: changing content on the page.

    In your index.html:

    <p id="example">Original text</p>

    In your script.js:

    document.getElementById("example").innerText = "Hello, world!";

    How it will appear on your browser:

    Original Text

    Output: "Original text" changes to "Hello, world!".

Summary

JavaScript makes websites interactive.
Can be added inline, internal, external.
Use console.log() to test scripts.
Can manipulate page content using JS.
