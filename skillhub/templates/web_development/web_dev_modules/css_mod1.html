Lesson 1: What is CSS?

CSS stands for Cascading Style Sheets. It is used to style HTML elements e.g colors, fonts, spacing, layout, and positioning. Without CSS, HTML pages are plain and unstyled.

CSS "cascades" because styles can override each other based on specificity and order.
Example:

<p style="color: red;" >This is a red text</p>

How it will appear on your browser:

This is a red text

Lesson 2: How CSS Works with HTML

HTML - structure/content of the page.

CSS - style/presentation.
Browser combines both to show styled webpage.

Example : HTML + CSS

<head>
<style>
p{
color: blue;
font-size: 18px;
}
</style>
</head>
<body>
<p>Hello, World!</p>
</body>

How it will appear on your browser:

Hello, World!

p {color: blue; font-size: 18px;} - styles all <p> elements.

Lesson 3: Ways to Add CSS

Inline CSS - style applied directly on the element.

<p style="color: green;" >Hello</p>

Internal CSS - style written inside <style> in <head> in your .html file.

<head>
<style>
h1{
color: purple;
text-align: center;
}
</style>
</head>

External CSS - style in seperate .css file and linked in HTML.

<head>
<link rel="stylesheet" href="style.css">
</head>

It is recommended for large projects because it is cleaner and reuseable.

Lesson 4: Setting Up Your First CSS File

  • Create a file style.css in your project folder.
  • Write your first CSS rule:

    body{
    color: #f0f0f0;
    font-family: Arial, sans-serif;
    }

    This style applies to the body of your website.

  • Link to your HTML - write this in your index.html:

    <head>
    <link rel="stylesheet" href="style.css">
    </head>

  • Open HTML in browser - styles applied!

Summary

CSS = style in HTML.
Three ways to add CSS: inline, internal, and external.
Use external CSS for bigger projects.
CSS controls color, fonts, spacing, layout.
