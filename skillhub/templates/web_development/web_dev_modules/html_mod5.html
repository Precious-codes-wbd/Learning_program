Lesson 1: Adding Images <img>

The <img> tag is used to display images on a webpage.

<img src="image.jpg" alt="A beautiful scene">

How it will appear on your browser:

src - path to the image.
alt - text shows if image fails to load (also for accessibility).
Self-closing - no </img>

Lesson 2: Image Attributes (src, alt, width, height)

You can control the size and accessibility:

<img src="image.jpg" alt="A beautiful scene" width="300" height="200">

width and height - in pixels.
Keep alt for screen readers and SEO.

Lesson 3: Image Paths (Relative vs Absolute)

Relative Path - Files in your project folder.

<img src="images/photo.jpg" alt="My Photo">

Absolute Path - Full URL from internet.

<img src="https://example.com/photo.jpg" alt="Online Photo">

Lesson 4: Adding Videos

Use <video>:

<video width="320" height="240" controls>
<source src="movie.mp4" type="video/mp4">
Your browser does not support the video tag.
</video>

How it will appear on your browser:

Controls - shows play, pause buttons.
<source> - video type and file.

Lesson 5: Adding Audio

Use <audio>:

<audio controls>
<source src="song.mp3" type="audio/mpeg">
Your browser does not support the audio element.
</audio>

How it will appear on your browser:

Controls - play/pause buttons.
<source> - audio file.

Summary

<img> - display images(src, alt, width, height).
Relative vs absolute paths - project vs web.
<video> - display video with controls.
<audio> - play audio with controls.

Steps to Adding Images, Videos and Audio to your Folder:

  1. Go to File Explorer, copy the image you want to use.
  2. Then go to your folder(Project) in documents, create a folder and name it 'Images'.
  3. Then paste the image copied.
  4. Since it is in a folder, you have to call it differently :
    • Since the name of your image folder is 'Images', and let's say the name of your image is picture.jpeg.
    • You call it thus: <img src="Images/picture.jpeg" alt="My Picture">
  5. Do the same for videos and audio.
