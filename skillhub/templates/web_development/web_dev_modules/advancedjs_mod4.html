Lesson 1: Click Events

Detects when a user clicks an element.

const button = document.getElementById("myButton");
button.addEventListener("click", () => {
alert("Button clicked!");
});

addEventListener("click", function) - runs code when clicked.

Lesson 2: Mouse Events

Detects mouse actions: hover, enter, leave, move.

const box = document.getElementById("box");
box.addEventListener("mouseover", () => {
box.style.backgroundColor = "yellow";
});

box.addEventListener("mouseout", () => {
box.style.backgroundColor = "lightblue";
});

mouseover - mouse enters element.
mouseout - mouse leaves element.

Lesson 3: Keyboard Events

Detects typing or key presses.

const input = document.getElementById("nameinput");
input.addEventListener("keydown", (event) => {
console.log("Key pressed:" event.key);
});

keydown - when key is pressed.
keyup - when key is released.
keypress - old method, less used now.

Summary

Click events - respond to clicks on buttons, links, or any element.
Mouse events - respond when the mouse moves, enters, or leaves elements.
Keyboard events - respond when the user types or presses keys.
Event handling makes your site interactive and responsive to users.
