Lesson 1: CSS Colors

CSS allows you to change the color of text, backgrounds, and other elements. You can use named colors, HEX codes, RGB, or HSL.

Examples:

  1. Named color:

    p{
    color: red;
    }

  2. HEX code:

    p{
    color: #ff5733;
    }

  3. RGB:

    p{
    color: rgb(255, 87, 51);
    }

  4. HSL:

    p{
    color: hsl(10, 100%, 60%);
    }

Lesson 2: Background Colors

Use background color to color the background of elements.

Example:

In your index.html:

<div>
<p>This is a paragraph</p>
<span>A span text</span>
</div>

In your style.css:

div{
background-color: lightblue;
}

How it will appear on your browser:

This is a paragraph

A span text

Works with any HTML element (div, p, header, section, e.t.c)

Lesson 3: Font Family

Control the type of font using font family. Always provide a fallback font in case the first one isn't available.

Example:

div{
font-family: Arial, sans-serif;
}

"Arial" - primary font.
"sans-serif" - fallback.

Lesson 4: Font Size

Change size of text using font-size.

Example:

h2{
font-size: 36px;
}

p{
font-size: 60rem;
}

Can use px, em, rem, or %.

Lesson 5: Text Alignment and Decoration

Text Alignment:

h1{
text-align: center;/* left, right, center, justify */
}

Text Decoration:
In your index.html:

<div>
<a href="#">A link</a>
<p>A normal text</p>
</div>

In your style.css:

a{
text-decoration: none;/* remove underlines from links */
}

p{
text-decoration: underline;
}

How it will appear on your browser:

A link

A normal text

Text-transform - uppercase, lowercase, capitalize
Letter-spacing - space between letters (use px).

Summary

Colors: text, background, borders.
Font-family & size: control text appearance.
Text-alignment & decoration: style text position, underline, capitalization.
CSS enhances readability and presentation.
