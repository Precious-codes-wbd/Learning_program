Lesson 1: Function Declaration

Functions are blocks of code that perform a task. Declared using the function keyword.

function greet(){
console.log("Hello, Precious!");
}
greet(); // Call the function.

greet() - executes the code inside the function.
Functions help avoid repeating code.

Lesson 2: Function Parameters

Parameters let you pass information into a function.

function greetUser(name){
console.log("Hello," + name + "!");
}
greetUser(Precious); // Hello, Precious!.

Parameters make your functions dynamic and flexible.

Lesson 3: Return Values

return allows a function to give a value back.

function add(a,b){
return a + b;
}
let sum = add(5, 3);
console.log(sum); //8

You can store the returned value in a variable.

Lesson 4: Arrow Functions

Shorter syntax for writing functions (ES6).

const greet = (name) => {
console.log(Hello, ${name}!);
}
greet("Precious"); // Hello, Precious!

For single-line functions, you can omit {} and return.

const add = (a, b) => a + b;
console.log(add(5, 3)) //8

Summary

Functions organize code and avoid repetition.
Parameters make functions flexible.
Return values let functions give results back.
Arrow functions = shorter, modern syntax.
