Lesson 1: Introduction to Flexbox

Flexbox is a CSS layout system to arrange elements efficiently in a row or column. It makes aligning, spacing, and distributing items much easier than old methods (like floats).
Flexbox works on a parent container and its direct children.

Why use Flexbox:

  • Center items easily.
  • Controls spacing between elements.
  • Change direction (row/column) without changing HTML.
  • Makes responsive design easier.

Lesson 2: Flex Container

To use Flexbox, set the parent element as a flex container:

In your index.html:

<div class="container">
<div>Item 1</div>
<div>Item 2</div>
<div>Item 3</div>
</div>

In your style.css:

.container{
display: flex;
}

All direct children becomes flex items.

How it will appear on your browser:

Item 1
Item 2
Item 3

By default items are arranged horizontally in a row.

Lesson 3: Flex Direction

flex-direction controls main axis (row or column).

Values:
row - horizontal(default).
row-reversed - horizontal reversed.
column - vertical.
column-reverse - vertical reversed.

.container{
display: flex;
flex-direction: column; /* items stacked vertical */
}

Lesson 4: Justify Content

Controls alignment along the main axis (row or column).

Values:
flex-start - align to start.
flex-end - align to end.
center - center.
space-between - equal spaces between items.
space-around: equal space around items.

.container{
display: flex;
justify-content: space-between; /* spread items evenly */
}

Lesson 5: Align Items

Controls alignment along the cross axis (perpendicular to main axis).

Values:
flex-start - top(for-now)
flex-end - bottom(vertically).
center - center vertically.
stretch - stretch items to container.

.container{
display: flex;
align-items: center; /* items verticaly centered */
height: 200px; /* container height for cross axis.
}

Summary

Flexbox = flexbox layout system.
Flex container = display: flex
Flex direction: row, row-reverse, column, column-reverse.
Justify content: align along main axis.
Align items: align along cross axis.
Use Flexbox for responsve layouts and easy alignment.
