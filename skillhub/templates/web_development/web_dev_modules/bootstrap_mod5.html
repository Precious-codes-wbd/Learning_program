Lesson 1: Spacing Utilities

Bootstrap spacing classes adjusts margin (m-) and padding (p-).
Syntax: {property}{sides}-{size}

Property Sides Examples
m all m-3 - margin on all sides
mt top mt-2 - margin-top
mb bottom mb-4 - margin-bottom
ms left/start ms-2 - margin-left(start)
p all p-3 - padding on all sides
pe right/end pe-2 - padding-right(end)

Size range: 0 - 5

<body>
<div class="p-3 mb-2 bg-primary text-white">Box with padding and margin</div>
</body>

How it will appear on your browser:

Box with padding and margin

Lesson 2: Display Utilities

Control visibility and control with classes:

Class Effect
d-none hide element
d-block display block
d-inline display inline
d-flex display flex
d-inline-block inline block

Can combine with breakpoints:

<body>
<div class="d-none d-md-block bg-success text-white p-2">Only visible on medium and larger screens</div>
</body>

How it will appear on your browser:

Only visible on medium and larger screens.

Hidden on small screens, visible on ⪰ 768px.

Lesson 3: Responsive Images

Images automatically scale to parent container.

<body>
<img class="img-fluid" src="Images/picture.jpeg" alt="Responsive Image">
</body>

How it will appear on your browser:

Keep images responsive across devices.

Summary

Spacing utilities: control margin and padding easily.
Display utilities: show/hide elements and change layout (d-block, d-none, etc.)
Responsive images: img-fluid makes images scale automatically.
Helps your website look perfect on mobile, tablet, and desktop.
