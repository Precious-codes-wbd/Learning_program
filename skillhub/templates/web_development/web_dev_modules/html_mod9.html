Lesson 1: What is Semantic HTML?

Semantic HTML uses tags that descriibe their meaning. Help browsers, developers, and search engine understand content.
Examples: <header>, <section>, <article> and <footer>.

Lesson 2: <header>

Represents the top section of a page, usually contains logo, title, navigation.

<header>
<h1>My Website</h1>
<nav>
<a href="index.html">Home</a>
<a href="about.html">About</a>
</nav>
</header>

How it will appear on your browser:

My Website

Home About

Lesson 3: <section>

Represents a thematic grouping of content. Think "a block of related content"

<section>
<h2>About Me</h2>
<p>This is my bio...</p>
</section>

How it will appear on your browser:

About Me

This is my bio...

Lesson 4: <article>

Represents independent content. Can be reused or shared individually.

<article>
<h2>Blog Post</h2>
<p>This is a blog article...</p>
</article>

How it will appear on your browser:

Blog Post

This is a blog article...

Lesson 5: <footer>

Represents the bottom section of a page. Usually contains copyright, contact info, links.

<footer>
<p>© 2026 Precious's Website</p>
</footer>

How it will appear on your browser:

© 2026 Precious's Website

Summary

Semantic tag describe the content. <header> - top.
<section> - grouped content.
<article> - independent content.
<footer> - bottom of the page.
Benefits: Accessibility, SEO, and clarity.
