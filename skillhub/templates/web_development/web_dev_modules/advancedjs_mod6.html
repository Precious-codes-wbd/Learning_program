Lesson 1: Image Slider

Image slider shows multiple images one at a time with navigation

In your Index.html:

<div id="slider">
<img class="slide" src="Images/picture1" alt"Image Slider" style="height: 450px; width: 100%; object-fit: cover; display: block;">
<img class="slide" src="Images/picture2" alt"Image Slider" style="height: 450px; width: 100%; object-fit: cover; display: block;">
<img class="slide" src="Images/picture3" alt"Image Slider" style="height: 450px; width: 100%; object-fit: cover; display: block;">
<button id="next" class="btn btn-primary" style="margin-top: 10px;">Next</button>
</div>

In your script.js:

const slides = document.querySelectorAll(".slide");
let current = 0;
document.getElementById("next").addEventListener("click", () => {
slides[current].style.display ="none";
current = (current + 1) % slides.length;
slides[current].style.display ="block";
});

How it will appear on your browser:

How it works:

Only one image is visible at a time and that is because of the CSS property: display.
Clicking next shows the next image.

The images are called using querySelectorAll(.slide), then the button is called and given a function - click so when clicked it should set the current images which is 0 to be display:none.

After that it should add 1 i.e bring/call the next image and give it display:block.
% slides.length - loops back to the first image.

Lesson 2: To-Do List App

To do app lets users add and remove tasks.

In your Index.html:

<input type="text" id="taskInput">
<button id="addTask" class="btn btn-warning" style="margin-top: 10px;">Add</button>
<ul id="taskList">Add</ul>

In your script.js:

document.getElementById("addTask").addEventListener("click", () => {
const input = document.getElementById("taskInput");
if(input.value !== ""){
const li = document.createElement("li");
li.innerText = input.value;
li.addEventListener("click", () => li.remove());
document.getElementById("taskList").appendChild(li);
input.value = "";
});

How it will appear on your browser:

    How it works:

    The button is called, when clicked, the input is called. We have an if statement saying if the input is not empty, it should create an li element. Whatever is inputed in the input should be written in the list(li).

    To remove a task, the list is given a function, when clicked, it should remove.
    In module 5, we discussed creating elements, after the elements are created they are appended to the page likewise here, li is being appended to the page.

    When you click a task - removes it.

    Lesson 3: Modal Popup

    Popup window triggered by a button.

    In your Index.html:

    <button id="openModal" class="btn btn-success">
    <div id="modal" class="modal" style="display: none">
    <div class="modal-dialog modal-dialog-centered">
    <div class="modal-content">
    <span id="closeModal">×</span>
    <p>This is a popup!</p>
    </div>
    </div>
    </div>

    In your script.js:

    const modal = document.getElementById("modal");
    document.getElementById("openModal").addEventListener("click" () => {
    modal.style.display = "block";
    });
    document.getElementById("closeModal").addEventListener("click" () => {
    modal.style.display = "none";
    });

    How it will appear on your browser:

    ×

    This is a popup!

    How it works:

    The modal is a bootstrap property and is given a display property of none.

    The button openModal is given a function when clicked it should given the called modal a display property of block and the span closeModal does the opposite returning the back to its former style.

    Modal-dialog modal-dialog-centered centers the modal.

    Summary

    Image Slider: cycle through images dynamically.
    To-do list app: add/remove items interactively.
    Modal popup: show/hide content on demand.
    Combines DOM selection, events, creation/removal, and style manipulation.
