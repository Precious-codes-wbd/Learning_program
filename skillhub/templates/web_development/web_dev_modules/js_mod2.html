Lesson 1: Variables (let, const, var)

Variables are containers for storing data values. JS uses three ways to declare variables:

  • let - can change value later.

    let name = "Minnie";
    name = "Precious"; // updated value
    console.log(name); // Precious

  • const - cannot change value once set.

    const birthYear = "2008";
    console.log(birthYear); // 2008

  • var - older way, can also change value, but less recommended.

    var name = "17";
    age = "18";
    console.log(age); // 18

Best practice: Use let or const instead of var.

Lesson 2: Strings

Strings = text data, always inside quotes '' or "".

let greeting = "Hello Precious";
console.log(greeting);

Can combine strings using concatenation (+).

let firstName = "Minnie";
let lastName = "Teddy";
console.log(firstName + " " + lastName); // Minnie Teddy

" " indicates space.

Can also use template literals ()

let firstName = "Minnie";
let lastName = "Teddy";
console.log(Hello, ${firstName} ${lastName}!)

Lesson 3: Numbers

Numbers = numeric data (integers or decimals).

let age = 17;
let price = 199.99;
console.log(age, price);

Can perform math operations: +, -, *, /, %

console.log(10 + 5); // 15
console.log(8 - 7); // 1

Lesson 4: Booleans

Boolean = true or false. It is used in conditions.

let isStudent = true;
let isGraduated = false;
console.log(isStudent, isGraduated);

Lesson 5: Arrays

Arrays = stores multiple values in a single variable

indexNumber =[" 0 ", " 1 ", " 2 "];
let fruit = ["apple", "banana", "mango"];
console.log(fruits[0]); //apple

You can add, remove, or loop through items in array.

Summary

Variables store data values: let, const, var.
Data types: strings, numbers, booleans, arrays.
Strings can be concatenated or use template literals.
Arrays hold multiple elements.
Booleans are used for true/false decisions.
