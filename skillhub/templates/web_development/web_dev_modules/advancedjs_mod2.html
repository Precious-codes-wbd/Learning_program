Lesson 1: getElementById()

Selects a single element by its id.

In your Index.html:

<h1 id="myHeading">My Heading</h1>
<p>A paragraph</p>

In your script.js:

const heading = document.getElementById("myHeading");
heading.style.color = "blue";

How it will appear on your browser:

My Heading

A paragraph

Returns one element only.

Lesson 2: getElementByClassName()

Selects all elements with a specific class.

In your Index.html:

<p class="box">Box 1</p>
<p class="square">A paragraph</p>
<p class="box">Box 2</p>

In your script.js:

const boxes = document.getElementByClassName("box");
boxes[0].style.backgroundColor = "yellow"; // first box

How it will appear on your browser:

Box 1

A paragraph

Box 2

Returns an HTML Collection - like an array but not exactly.
Use [index] to access a specific element.

Lesson 3: getElementsByTagName()

Selects all elements with a specific tag name.

In your Index.html:

<p>First paragraph</p>
<p>Second paragraph</p>
<h1>Heading</h1>

In your script.js:

const paragraphs = document.getElementByTagName("p");
paragraphs[1].innerText = "Changed text"; // second paragraph

How it will appear on your browser:

First Paragraph

Changed text

Third paragraph

Returns HTMLCollection

Lesson 4: querySelector()

Selects the first element that matches a CSS selector.

const firstDiv = document.querySelector(".container");
firstDiv.style.border = "2px solid red";

Works with IDs, classes, tags, or combinations.

Lesson 5: querySelectorAll()

Selects all elements that match a CSS selector.

const allDivs = document.querySelectorAll("div.container");
allDivs.forEach(div => {
div.style.padding = "10px";
});

Returns a NodeList - can use forEach()
Very flexible and modern way to select multiple elements.

Summary

getElementById() - select one element by ID.
getElementByClassName() - selects all elements by class.
getElementsByTagName() - selects all elements by tag.
querySelector() - selects first element by CSS selector.
querySelectorAll() - selects all elements by CSS selector.
