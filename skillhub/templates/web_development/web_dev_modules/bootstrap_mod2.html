Lesson 1: Rows and Columns

Bootstrap grid uses rows and columns to arrange content.

<body>
<div class="container">
<div class="row">
<div class="col">
Column 1
</div>
<div class="col">
Column 2
</div>
<div class="col">
Column 3
</div>
</div>
</div>
</body>

How it will appear on your browser:

Column 1
Column 2
Column 3

.row - contains columns.
.col - divides the row equally.
You can create up to 12 columns in a row.

Lesson 2: Grid Breakpoints

Breakpoint control layout changes on different screen sizes. Bootstrap uses these prefixes:

Prefix Screen size
col-sm Small ⪰ 576px
col-md Medium ⪰ 768px
col-lg Large ⪰ 992px
col-xl Extra Large ⪰ 1200px
col-xxl XXL ⪰ 1400px

Example:

<body>
<div class="container">
<div class="row">
<div class="col-sm-6 col-md-4">
Box 1
</div>
<div class="col-sm-6 col-md-4">
Box 2
</div>
<div class="col-sm-12 col-md-4">
Box 3
</div>
</div>
</div>
</body>

How it will appear on your browser:

Box 1
Box 2
Box 3

On small screens, first 2 columns share space, third takes full width.
On medium and large screens, each column takes 1/3 of the row.

Lesson 3: Responsive Layouts

Combine rows, columns, and breakpoints to make layouts adapt to devices.

<body>
<div class="container">
<div class="row">
<div class="col-12 col-md-8>
Main Content
</div>
<div class="col-12 col-md-4">
Sidebar
</div>
</div>
</div>
</div>
</body>

How it will appear on your browser:

Main Content
Sidebars

On phones, sidebar moves below main content.
On tablets/desktops, sidebar sit next to main content.

Summary

Rows contains columns - core of Bootstrap grid.
Columns divide space - up to 12 per row.
Breakpoints adjust layout for different screen sizes.
Combines rows, columns, breakpoints - reasponsive layouts.
